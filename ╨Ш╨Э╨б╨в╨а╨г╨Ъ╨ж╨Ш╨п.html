🍽️ ЭФИР — Инструкция по запуску

Шаг 1 — Установить Node.js (один раз)

Node.js — это программа, которая запускает сайт на вашем компьютере.

📥 Скачать Node.js

Нажмите кнопку выше → скачайте файл → установите как обычную программу → перезагрузите компьютер

Шаг 2 — Запустить сайт

1 Найдите файл START_WINDOWS.bat в этой папке

2 Сделайте двойной клик по нему

3 Если появится предупреждение Windows — нажмите "Подробнее" → "Выполнить в любом случае"

4 Откроется чёрное окно — не закрывайте его! Там работает сайт

5 Через ~30 секунд браузер откроется сам

Как войти в панель администратора

1 Откройте в браузере: Войти на сайт

2 Введите номер телефона:

+77001234567

3 Нажмите "Получить код"

4 Переключитесь в чёрное окно — там будет строка:

[SMS DEV] Код для +77001234567: 123456

5 Введите 6-значный код на сайте

6 Готово! Панель администратора: Открыть админку

Если что-то не работает

Браузер показывает "Сайт недоступен":

→ Подождите ещё 30-60 секунд — сайт ещё загружается
→ Убедитесь что чёрное окно открыто и не показывает ошибок
→ Попробуйте открыть вручную: http://localhost:3000

Чёрное окно сразу закрывается:

→ Node.js не установлен или нужна перезагрузка компьютера

Долго устанавливается (первый раз):

→ Это нормально! Первый запуск — 5-10 минут. Следующие — 10 секунд.
