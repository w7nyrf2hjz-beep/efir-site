EFIR - Food Delivery Website
=============================

STEP 1: Install Node.js (one time only)
  Website: https://nodejs.org
  Click the green LTS button, install, restart computer.

STEP 2: Start the website
  Double-click: START_WINDOWS.bat

  Windows warning? Click More info -> Run anyway

STEP 3: Wait
  First run: 5-10 minutes (downloads components)
  Next runs: about 30 seconds
  Browser opens automatically at http://localhost:3000

ADMIN LOGIN:
  1. Open: http://localhost:3000/auth
  2. Phone: +77001234567
  3. Click Get code button
  4. Look at the black window - code appears there
  5. Enter the 6-digit code on the website

IMPORTANT: Do NOT close the black window!
